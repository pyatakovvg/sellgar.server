# docs

`docs` содержит agent-facing и developer-facing документацию для
`sellgar.server`.

## Правила

- Новую документацию писать на русском языке.
- Не переносить пути, команды и термины из другого проекта без адаптации.
- Документ должен иметь конкретный scope: repo, workspace, layer или task type.
- Не дублировать `AGENTS.md`, если достаточно ссылки.
- Если меняется структура workspace, обновить ближайший `AGENTS.md`.

## Проверка

Для документационных изменений:

```bash
git diff --check
```

Также проверить поиском, что не осталось терминов из чужого проекта.
