# Правила Agent-Friendly Документации

Документ для агента должен быть коротким протоколом действий.

## Хороший Документ

- имеет конкретный scope;
- говорит, когда его читать;
- называет владельца и границы;
- дает проверку;
- не пересказывает весь код;
- не дублирует соседний `AGENTS.md`.

## Когда Добавлять Правило

Добавлять правило, если оно предотвращает реальную ошибку:

- неверный workspace-владелец;
- перенос бизнес-логики между gateway/service;
- неправильная проверка;
- повторяющаяся ошибка структуры каталогов;
- security/auth/session риск.

Не добавлять общую best practice без привязки к текущему repo.
