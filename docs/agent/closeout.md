# Завершение Задачи

Перед финальным ответом проверить:

- изменен только нужный scope;
- нет случайных правок в generated/cache/node_modules;
- выполнена проверка из ближайшего `AGENTS.md`;
- для документации выполнен `git diff --check`;
- для кода выполнен build/test затронутого workspace.

В финальном ответе указать:

- что изменено;
- какие проверки выполнены;
- что не проверялось и почему;
- оставшиеся риски.
