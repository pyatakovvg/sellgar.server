# Общие Правила Локальных AGENTS.md

## Ответственность

- Описывать локальные отличия, не копировать весь родительский документ.
- Указывать владельца слоя и команду проверки.
- Не закреплять временное состояние кода как норму.

## Проверка

Если локальный `AGENTS.md` задает проверку, использовать ее. Если нет:

- для gateway: `yarn workspace @gateway/<name> run build`;
- для service: `yarn workspace @service/<name> run build`;
- для документации: `git diff --check`.

## Изменения

При изменении структуры каталога обновить ближайший `AGENTS.md` в той же правке.
