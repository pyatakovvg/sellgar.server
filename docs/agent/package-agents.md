# Пакетные AGENTS.md

Scope: project-specific overlay.

Локальный `AGENTS.md` нужен, если каталог имеет отдельную ответственность,
команды проверки или архитектурные ограничения.

## Содержимое

- Назначение каталога/workspace.
- Ключевые файлы.
- Границы ответственности.
- Что нельзя размещать внутри.
- Что сверять при изменении.
- Команда проверки.

## Где Нужен

- `gateways/*`;
- `services/*`;
- крупные доменные поддеревья с нетривиальными правилами;
- `docs`, если меняются agent-facing инструкции.

Не создавать локальный `AGENTS.md`, если он только повторяет родительский.
